# feicoop-wp-template

WordPress theme ported from the Publii FEICOOP theme.

## Download

To get a ZIP package ready to upload in WordPress:

1. Open the repository on GitHub.
2. Go to `Actions` and run the `Package theme` workflow manually, or create a tag that starts with `v` and push it.
3. Download the `feicoop-wp-template.zip` artifact from the workflow run, or use the ZIP attached to the GitHub Release.

The ZIP includes the theme root files only, so it can be uploaded directly in `Appearance > Themes > Add New > Upload Theme` in WordPress.
